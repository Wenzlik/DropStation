# DropStation Privacy Policy

Last updated: 2026-05-29

DropStation does not collect, transmit, sell, or share personal
data.

DropStation communicates directly with the Synology NAS that you
configure in the app. Your server address, session state, cookies,
and trusted-certificate fingerprints are stored locally on your
device using iOS system storage such as Keychain and UserDefaults.
They are not sent to DropStation, the developer, analytics
providers, advertising networks, or any third-party backend.

DropStation has no account system, telemetry SDK, analytics SDK,
advertising SDK, crash-reporting SDK, or remote logging service.
TestFlight crash and hang diagnostics, if any, are provided by
Apple through App Store Connect as part of Apple's beta
distribution system.

Bug reports are opt-in. If you use Settings -> Report a bug,
DropStation opens your own mail app and lets you review the
message before sending it. Optional diagnostics may include app
version, build number, iOS version, device model identifier, NAS
host name, authentication method label, session state label, and
capture timestamp.

Bug reports never include passwords, session IDs, cookies, OTP
codes, authentication tokens, torrent names, download URLs, or
file names.
