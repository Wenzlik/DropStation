# DropStation 0.5.0

## Release type

Major UI modernization release.

DropStation 0.5.0 transforms the app from a basic SwiftUI utility project into a cohesive dashboard-first NAS companion experience.

---

# Highlights

## Dashboard-first UX

New home experience with:
- live NAS overview
- transfer metrics
- activity feed
- quick actions
- clearer session state

---

## Redesigned Downloads screen

Downloads now use:
- grouped activity-list presentation
- calmer metadata hierarchy
- thinner progress indicators
- modern utility-app density

---

## Redesigned Settings screen

Settings now feature:
- account identity hero
- grouped sections
- modern hierarchy
- improved readability
- cleaner destructive actions
