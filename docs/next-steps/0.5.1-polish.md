## 1. Dashboard idle-state polish

### Problem

Current hero can show:

```text
0 KB/s
Working...
40 active
```

This feels inconsistent and resembles a stuck/frozen state.

### Desired behavior

#### Active transfer

```text
18.4 MB/s
Downloading
3 active
```

#### Idle but tasks exist

```text
40 Downloads
NAS is idle
```

or

```text
40 Tasks
Currently idle
```

#### No tasks

```text
All caught up
No active downloads
```

### Acceptance criteria

- Do not show 0 KB/s as the hero focal number when nothing is transferring.
- Do not show "Working..." when both download and upload speed are zero.
- Idle state should feel intentional and calm.

## 2. Downloads readability polish

### Problem

The Downloads list is visually improved but still slightly too dense.

### Goals

- Reduce visual competition between:
  - title
  - metadata
  - size
  - chevron
- Make metadata quieter.
- Keep compact density.
- Preserve activity-list feel.
- Avoid returning to giant cards.

### Acceptance criteria

- Long torrent names are easier to scan.
- Metadata hierarchy is calmer.
- The title remains dominant.
- Separators feel lighter.

---

## 3. Light-mode contrast polish

### Problem

Dark mode looks premium.
Light mode feels flatter because surfaces blend together.

### Goals

- Improve surface separation in light mode.
- Slightly stronger borders or grouped-surface contrast.
- Preserve subtle aesthetic.

### Acceptance criteria

- Cards are easier to distinguish in light mode.
- Dark mode appearance remains unchanged.

---

## 4. Settings destructive-action polish

### Problem

"Forget this device" visually competes with "Sign out".

### Goals

- Keep "Sign out" visible.
- Reduce visual weight of destructive action.
- Preserve discoverability.

### Acceptance criteria

- Destructive action remains accessible.
- It no longer dominates the account hero section.

---

## 5. In-app changelog cleanup

### Problem

The bundled changelog is too technical for end users.

### Goals

- Keep in-app changelog short and user-facing.
- Move implementation detail to GitHub release notes.

### Do not include

- internal component names
- DesignSystem internals
- NWPathMonitor
- UserDefaults
- low-level implementation details
- architecture commentary

### Suggested 0.5.1 entry

```markdown
## 0.5.1 - Polish update

### Improved
- Better dashboard idle state
- Improved readability in the Downloads list
- Better light mode contrast
- Cleaner Settings actions
- Shorter, more user-friendly in-app changelog

### Fixed
- Dashboard no longer shows a confusing "0 KB/s / Working..." state when the NAS is idle
```
